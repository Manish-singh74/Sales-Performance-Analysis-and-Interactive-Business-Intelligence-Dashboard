Sales Performance Dashboard
Project Overview

This project focuses on analyzing a real-world sales dataset to identify revenue trends, profitability, product performance, customer purchasing behavior, and regional sales performance. The project follows an end-to-end data analytics workflow using Excel, SQL, Python, and Power BI.

Objectives
Clean and preprocess raw sales data.
Analyze sales, profit, quantity, and profit margin.
Identify top-performing products and categories.
Evaluate regional sales performance.
Analyze yearly and monthly sales trends.
Create an interactive Power BI dashboard.
Generate actionable business insights.
🛠️ Tools & Technologies
Excel – Data cleaning and preprocessing
SQL – Data storage and database management
Python – Data analysis
NumPy & Pandas – Statistical and exploratory analysis
Matplotlib – Data visualization
Power BI – Interactive dashboard development
GitHub – Project documentation and version control
Project Workflow

Raw Dataset → Excel Cleaning → SQL Database → Python Analysis → Power BI Dashboard → Business Insights

📈 Key Analysis

The dataset contains 50,000 sales records covering multiple years, categories, products, regions, and sales channels.

Major findings include:

Total Sales: ₹2.18 Billion
Total Profit: ₹191.55 Million
Total Quantity: 149,676
Top Category: Electronics
Top Product: Laptops
Top Region: North
Highest Sales Month: April
Lowest Sales Month: September

💡 Business Insights

Electronics contributes the largest share of revenue, while laptops and mobiles are the strongest products. North region generates the highest sales. Sales decline significantly during September, indicating a potential seasonal opportunity. Profitability should also be monitored for low-margin and loss-making transactions.

🚀 Future Scope

Future improvements can include sales forecasting, customer segmentation, predictive analytics, automated reporting, and machine-learning-based demand prediction.
